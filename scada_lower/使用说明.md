# 空压站 SCADA 下位机模拟器使用说明

## 功能概述

本模拟器提供5个设备的完整工艺数据模拟：
- **从站1-3**: 空压机1、空压机2、空压机3
- **从站4**: 储气罐
- **从站5**: 干燥机

## 启动方法

```bash
cd scada_lower
python main.py
```

## 界面说明

### 顶部控制栏

1. **▶ 启动服务器**: 启动Modbus TCP服务器，开始监听端口（默认502）
2. **⏹ 停止服务器**: 停止Modbus TCP服务器
3. **🔌 断开连接**: 模拟网络中断，停止服务器但保持UI运行
4. **🔄 重新监听**: 重新启动服务器监听端口
5. **端口输入框**: 设置Modbus TCP监听端口号
6. **状态显示**: 显示当前服务器运行状态

### 设备标签页

每个设备标签页包含：

#### 实时数据区
显示该设备的关键工艺参数：

**空压机（从站1-3）**:
- 排气压力（bar）- 正常范围：6.0-8.0
- 排气温度（℃）- 正常范围：70-85
- 运行状态（0=停机, 1=运行, 2=故障）
- 加载/卸载状态
- 运行电流（A）
- 故障码

**储气罐（从站4）**:
- 罐压（bar）- 正常范围：7.5-8.5
- 温度（℃）- 正常范围：30-40

**干燥机（从站5）**:
- 进口压力（bar）
- 出口压力（bar）
- 露点（℃）- 正常范围：-45至-35
- 运行状态
- 再生状态（除湿中/再生中）

#### 故障注入控制区

4个控制按钮：

1. **⚠ 强制超限**: 将关键参数拉到超限值
   - 空压机/储气罐：压力拉到10.5 bar（超过10.0报警阈值）
   - 干燥机：露点拉到-15℃（超过-20℃报警阈值）

2. **〰 制造抖动**: 在阈值附近制造抖动数据
   - 压力在7.5-8.1 bar之间跳动
   - 温度在87-91℃之间跳动
   - 用于测试上位机防抖功能

3. **🔴 稳定故障**: 制造稳定超限并触发故障状态
   - 压力/温度持续超限
   - 设备状态切换为故障（状态=2）
   - 设置故障码

4. **✅ 恢复正常**: 将所有参数恢复到正常值
   - 压力恢复到7.0 bar
   - 温度恢复到75℃
   - 设备状态恢复为运行（状态=1）
   - 清除故障码

#### 状态显示
- 绿色：正常运行
- 橙色：数据抖动
- 红色：参数超限
- 深红色：稳定故障

#### 🔄 刷新数据
手动刷新当前显示的数据（定时器每500ms自动刷新）

## 数据自动变化特性

### 压力变化
- 空压机加载时压力缓慢上升（约0.01 bar/200ms）
- 空压机卸载时压力缓慢下降
- 达到8.0 bar自动卸载，低于6.0 bar自动加载
- 储气罐压力小幅随机波动

### 温度变化
- 加载时温度缓慢上升
- 卸载时温度缓慢下降或稳定
- 小幅随机波动（±0.02℃）

### 状态切换
- 空压机根据压力自动切换加载/卸载
- 干燥机每30秒自动切换除湿/再生状态
- 可通过上位机写入线圈/寄存器改变运行状态

## Modbus寄存器映射

### 保持寄存器（可读写）

**空压机（从站1-3）**:
| 地址 | 参数 | 单位 | 说明 |
|------|------|------|------|
| 0 | 排气压力 | bar×100 | 750 = 7.5 bar |
| 1 | 排气温度 | ℃×10 | 750 = 75.0℃ |
| 2 | 运行状态 | - | 0=停机, 1=运行, 2=故障 |
| 3 | 加载/卸载 | - | 0=卸载, 1=加载 |
| 4 | 运行电流 | A×10 | 150 = 15.0A |
| 5 | 故障码 | - | 0=正常, 1=故障 |

**储气罐（从站4）**:
| 地址 | 参数 | 单位 | 说明 |
|------|------|------|------|
| 0 | 罐压 | bar×100 | 800 = 8.0 bar |
| 1 | 温度 | ℃×10 | 350 = 35.0℃ |
| 2 | 状态 | - | 1=运行 |

**干燥机（从站5）**:
| 地址 | 参数 | 单位 | 说明 |
|------|------|------|------|
| 0 | 进口压力 | bar×100 | 800 = 8.0 bar |
| 1 | 出口压力 | bar×100 | 780 = 7.8 bar |
| 2 | 运行状态 | - | 0=停止, 1=运行 |
| 3 | 露点 | ℃×10 | -400 = -40.0℃ |
| 4 | 再生状态 | - | 0=除湿, 1=再生 |

### 输入寄存器（只读）
与保持寄存器0-2地址相同，作为只读镜像

### 线圈（可读写）
支持写入控制，收到写入后改变设备运行状态

## 测试场景

### 场景1：正常数据采集
1. 启动服务器
2. 上位机读取各从站寄存器
3. 观察数据自动变化

### 场景2：报警测试
1. 点击"⚠ 强制超限"
2. 上位机检测到超限数据
3. 点击"✅ 恢复正常"
4. 上位机检测报警恢复

### 场景3：防抖测试
1. 点击"〰 制造抖动"
2. 数据在阈值附近跳动
3. 测试上位机防抖算法
4. 点击"✅ 恢复正常"

### 场景4：故障测试
1. 点击"🔴 稳定故障"
2. 设备状态变为故障
3. 上位机接收故障码
4. 点击"✅ 恢复正常"

### 场景5：网络中断测试
1. 点击"🔌 断开连接"
2. 上位机检测通信中断
3. 点击"🔄 重新监听"
4. 上位机恢复通信

### 场景6：上位机控制测试
1. 上位机写入运行状态到寄存器2
2. 观察设备状态变化
3. 上位机写入线圈控制启停
4. 观察反馈状态

## 性能特性

- **快速响应**: Modbus请求响应时间 < 10ms
- **高频读取**: 支持100ms轮询周期
- **不会卡顿**: 数据更新在独立线程
- **不会丢包**: pymodbus底层保证

## 注意事项

1. 首次启动可能需要管理员权限（如果使用502端口）
2. 可以使用1024以上端口避免权限问题
3. 断开连接后必须点击"重新监听"才能恢复
4. 故障注入功能只在当前模拟器生效，不影响Modbus通信
5. UI界面使用Fusion样式，简洁整齐

## 文件说明

- `main.py` - 主程序，包含UI界面
- `modbus_data_store.py` - Modbus数据存储
- `modbus_server.py` - Modbus服务器管理
- `compressor_simulator.py` - 空压机模拟器
- `tank_simulator.py` - 储气罐模拟器
- `dryer_simulator.py` - 干燥机模拟器
- `simulator_thread.py` - 模拟器更新线程
